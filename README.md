# 🎵 Ownsongs - Android Music Player

Ownsongs is an Android music player application developed using Kotlin and Android Studio. The application provides a simple, modern and dark-themed interface for browsing, searching and playing music.

## 📱 Features

- User Login
- User Signup
- Splash Screen
- Home Screen
- Music Search
- Music Library
- Music Player
- Play / Pause controls
- Previous / Next song controls
- Mini Player
- Dark-themed UI
- Fragment-based navigation
- Background music playback

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- XML
- Android SDK
- ViewBinding
- Android Fragments
- Gradle
